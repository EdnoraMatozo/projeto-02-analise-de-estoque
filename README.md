# Análise de Estoque com Python

Projeto de portfólio em Ciência de Dados desenvolvido para analisar níveis de estoque e identificar produtos que necessitam de reposição.

## Objetivo

Utilizar Python e análise de dados para transformar informações de estoque em indicadores que auxiliem no controle de produtos e na tomada de decisões.

## Tecnologias utilizadas

* Python
* Pandas
* Matplotlib
* Google Colab
* Jupyter Notebook

## Etapas da análise

* Importação e exploração da base de dados;
* Verificação e tratamento dos dados;
* Análise dos níveis de estoque;
* Comparação entre estoque atual e estoque mínimo;
* Identificação de produtos com baixo estoque;
* Análise dos produtos por categoria;
* Ordenação dos produtos de acordo com o nível de estoque;
* Criação de visualizações gráficas para facilitar a interpretação dos resultados.

## Critério de estoque crítico

Um produto foi considerado com baixo estoque quando:

`estoque atual <= estoque mínimo`

Esse critério permite identificar rapidamente os itens que necessitam de atenção ou reposição.

## Visualizações

Foram desenvolvidos gráficos para facilitar a análise, incluindo:

* Distribuição dos níveis de estoque;
* Estoque por categoria;
* Identificação de produtos abaixo do estoque mínimo;
* Comparação e ordenação dos produtos por nível de estoque.

## Aplicação

A análise demonstra como ferramentas de Ciência de Dados podem ser utilizadas no controle de estoque, permitindo identificar situações críticas e apoiar decisões relacionadas à reposição e ao gerenciamento de produtos.
